# PayPal Open Clone (Assignment-II)

A pixel-perfect clone of the PayPal Open landing page and Developer segment toggle, built using **React**, **Vite**, and **Tailwind CSS**.

## Features
- **Accurate Branding & Typography**: Authentic PayPal double-P monogram logo and refined typography matching the official design.
- **Top Navigation Bar**:
  - PayPal Logo
  - Dropdown navigation items (`Personal`, `Business`, `Developer`, `Partners`, `Useful Info`)
  - Pill action buttons (`Log In`, `Sign Up`)
  - Fully responsive mobile drawer
- **Segmented Control Switcher (Photos 1 & 2)**:
  - Interactive pill switcher supporting `Personal`, `Business`, and `Developer` (Photo 1)
  - `Business` view matches Photo 2 precisely:
    - **PayPal Open**
    - **One platform for your business needs**
    - Description text & dual action buttons (`Sign Up` and `Contact Sales`)
- **Static & Lightweight**: Clean static dataset and pure React state as specified in the assignment.

## Tech Stack
- **React 18**
- **Vite 6**
- **Tailwind CSS v4**
- **Lucide React** (icons)

## Getting Started

### 1. Run Locally
```bash
npm install
npm run dev
```

### 2. Build for Production
```bash
npm run build
npm run preview
```

### 3. Push to Your GitHub Account
```bash
git add .
git commit -m "Initial commit: PayPal Open clone with React and Vite"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git push -u origin main
```
